# Bocasion Móvil 📱

> Solución móvil para mejorar la gestión de la cafetería Bocasion

## Descripción

Bocasion Móvil es una aplicación móvil desarrollada en **Java** diseñada para optimizar y facilitar la gestión operativa de la cafetería Bocasion. Esta aplicación permite mejorar la experiencia tanto de los clientes como del personal administrativo.

## 🎯 Objetivos Principales

- Optimizar la gestión de inventario
- Facilitar la toma de pedidos
- Mejorar la experiencia del cliente
- Digitalizar procesos administrativos
- Aumentar la eficiencia operativa

## 📋 Características

- ✨ Interfaz intuitiva y amigable
- 📦 Gestión de inventario en tiempo real
- 🛒 Sistema de pedidos integrado
- 📊 Reportes y análisis de datos
- 👥 Gestión de usuarios y permisos
- 💳 Procesamiento seguro de transacciones

## 🛠️ Tecnologías Utilizadas

- **Lenguaje**: Java
- **Plataforma**: Android
- **Gestión de versiones**: Git & GitHub

## 📦 Requisitos Previos

- JDK 11 o superior
- Android SDK
- Android Studio
- Git

## 🚀 Instalación

1. **Clonar el repositorio**

   ```bash
   git clone https://github.com/Eduardo-Benjamin-Guevara/Bocasion_Movil.git
   cd Bocasion_Movil
````

2. **Abrir el proyecto en Android Studio**

   * Abre Android Studio
   * Selecciona **Open an Existing Project**
   * Navega a la carpeta clonada

3. **Sincronizar dependencias**

   * Android Studio sincronizará automáticamente las dependencias de Gradle.

4. **Ejecutar la aplicación**

   * Selecciona un emulador o dispositivo conectado.
   * Presiona el botón **Run (▶)**.

## 🔧 Configuración

### Variables de Entorno

Configura las siguientes variables según sea necesario:

* `API_BASE_URL` - URL base del servidor
* `DATABASE_PATH` - Ruta de la base de datos local

## 📝 Uso

### Iniciando sesión

1. Abre la aplicación.
2. Ingresa tus credenciales.
3. Accede al dashboard principal.

### Realizando un pedido

1. Navega a la sección **Pedidos**.
2. Selecciona los productos deseados.
3. Confirma y procesa el pago.
4. Visualiza el estado del pedido.
